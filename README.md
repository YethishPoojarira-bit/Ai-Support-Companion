# Ai Support Companion

This repository contains a set of example projects, demos, and tooling for building AI-assisted workflows and orchestration patterns.

Contents highlights:

- `CrewAI/` — example flows and crews for team-based agent orchestration.
- `LangGraph/` — experiments and agents that emphasize graph-based control flows.
- `SemanticKernal/` — samples focused on Semantic Kernel integrations and enterprise copilots.
- `WokingOnMCP/` — newly added local project containing two demos: `ADO_Issue_Creation` and `MCPServer_Demo`.
- `docs/framework_comparison.md` — a comparison guide describing when to use Semantic Kernel, LangGraph, CrewAI, and LlamaIndex (includes best-fit and possible scenarios).

Quick pointers:

- To review the framework comparison guide, open `docs/framework_comparison.md`.
- The `WokingOnMCP` folder was added and merged into `main`; note that nested repositories inside that folder were renamed from `.git` to `.git_backup` to allow tracking by this repo.
